# 何を作るか決めよう。

## AI開発アイデアアシスタント (Web Application)

> **「作りたいものが思いつかない？ だったら、AIに考えてもらおう。」**

「躊躇してないで、とにかく作ってみよう。」シリーズ第1弾。  
最初の1個を作り終えた後、「次は何を作ればいいか分からない」「自分の困りごとをどうツール化すればいいか分からない」という人のための無料Webアプリケーションです。

---

## 1. 特徴とコンセプト

- **完成されたアイデアは不要**: 普段感じている「面倒」「不便」「繰り返し作業」「手作業」を入力するだけで、AIが作れそうなツール候補を複数提案します。
- **次のステップへの直結導線**:
  - 慣れてきた人: そのまま PC の Antigravity IDE にプロンプトを送って直接開発。
  - じっくり進めたい人: 「躊躇してないで、とにかく作ってみよう。」へ進み、要件定義・仕様書作成からスタート。
- **Zero-Dependency & 高速動作**: 外部ライブラリに依存しない Pure HTML/CSS/JS 構成。
- **LocalStorage 状態保持**: ブラウザを閉じても入力内容が安全に復元されます。

---

## 2. 使い方（5ステップ）

1. **ようこそ**: コンセプトを確認してスタート。
2. **困りごと入力**: 「ファイル名変更が面倒」「Excelで同じ集計をしている」などの困りごとを入力（サンプル選択も可能）。
3. **AIへ質問文送信**: 生成された依頼文をワンタップでコピーし、AI（Antigravity IDE / ChatGPT / Claude等）に送信。
4. **アイデア候補の選択**: AIから提案された候補の中から「これを作ってみたい！」と思うものを1つ決定。
5. **開発へ進む**: 決まったアイデアを持って開発開始、または「躊躇してないで、とにかく作ってみよう。」へ連携。
